# IB Chemistry Practice

> **The latest version is on the [`ib-chemistry-practice`](https://github.com/allencallum51-coder/chemistry-organic-naming-practice-IB/tree/ib-chemistry-practice) branch.**
>
> This `main` branch only has the first version (organic nomenclature only).

The `ib-chemistry-practice` branch adds:

- **Unit 02 Isomers**: structural, cis-trans and optical isomers
- **Unit 03 Equations & amounts**: balancing, moles, limiting reactant, % yield, atom economy
- an **SL/HL switch**
- a full README explaining how to download and use the app

## Get the latest version

- **Just the app:** open [`index.html` on the `ib-chemistry-practice` branch](https://github.com/allencallum51-coder/chemistry-organic-naming-practice-IB/blob/ib-chemistry-practice/index.html), click **Download raw file**, then double-click the downloaded file to open it in your browser. You don't need to install anything, and it works offline.
- **Whole repo:** use the branch dropdown (top left, currently showing `main`) to switch to `ib-chemistry-practice`, then click **Code → Download ZIP**.
